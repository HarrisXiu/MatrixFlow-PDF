# MatrixFlow PDF application icon

Generated with the built-in image generation tool. `matrixflow-pdf.png` is the original artwork; `matrixflow-pdf.ico` contains Windows sizes 16, 20, 24, 32, 40, 48, 64, 128 and 256 px. PNG alpha is preserved. The frontend uses a 256 px copy in `frontend/public/app-icon.png` and a favicon ICO. The executable and native window share the ICO in this directory.

## Prompt adapted to the current brand

The artwork was generated before the project rename; the prompt below uses the current product name. The symbol itself contains no text and is unchanged.

Use case: logo-brand.
Asset type: production Windows desktop application icon for MatrixFlow PDF, also used at 36px in a dark React interface.
Primary request: Design one polished, distinctive Matrix-inspired document conversion icon. A bold folded-corner document silhouette formed from luminous mint-green solid geometric strokes, with a simple bold rightwards conversion arrow integrated into its lower half. Three short descending pixel-code bars tucked into the upper left of the document suggest digital code rain without tiny lettering.
Composition: one centered app icon, frontal flat view, square canvas 1024x1024. Dark charcoal rounded-square tile (#101512) occupies 92% of canvas with smoothly rounded corners; outside tile genuinely transparent. The green symbol fills most of the tile, generous but compact margins, strong silhouette legible at 16/32/48 pixels.
Style: premium minimal desktop utility branding, precise geometry, subtle emerald inner illumination, restrained depth, very clean crisp edges. Colors charcoal, emerald and pale mint (#91edb1).
Constraints: no text, no letters, no numbers, no watermark, no surrounding presentation or mockup, no extra icons, no full-scene code rain, no small decorative details, no Adobe or Microsoft logos. Output single finished icon with transparent exterior.
